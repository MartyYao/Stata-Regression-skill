# DID 跨组动态处理：无阈值连续分解（收敛边际 / 跨组边际 / 翻转频率）

> 用途：残差法 DV（dev=|ε|）拆分为 over/under 后，企业跨组动态（under→over、over→under）
> 挑战分组定义时的处理方案。触发：审稿人或用户质疑"从不足补成超发的企业算不算改善"、
> "补超后算不足组还是超额组"、under_intensity 的 0 值含义。
> 来源：论文1 dev 盲区诊断（2026-07-31），方案定稿于 F-001 §6。

## 问题链条（为什么需要这个方案）

1. **dev=|ε| 混杂方向**：+0.5 与 -0.5 都是"偏离 0.5"，但经济含义相反（超发=财政浪费/行为扭曲，
   不足=应得未得/企业被挤出）；政策机制也不同（识别效应补不足、压缩效应压超发）。
   dev 只能回答"配置效率整体是否改善"，回答不了"怎么改善"。dev 保留作总量证据
   （审稿人熟悉 Richardson 2006 传统），故事主线转向 over/under 关系。
2. **条件子样本 DV（under_v1/over_v1）的成员切换**：见 `inverted-v-pretrend-diagnosis.md`，
   标准修复是非条件 DV（`under_intensity = max(0,-e_v1)`，`over_intensity = max(0,e_v1)`）。
3. **非条件 DV 仍有盲区**：`max(0,-ε)` 的 0 值含义是"当前不在不足状态"，**不是"被做到位"**。
   两种情形都让 under_intensity 从 0.3 变 0：真命中（-0.3→-0.05）与翻转（-0.3→+0.3）。
   指标无法区分"向 0 收敛"与"穿过 0"——跨组动态挑战分组定义与指标解读。

## 第一版：四层动态检验（快速侦察，一个 do 文件跑完）

| 层 | 检验 | 用途 |
|:---|:---|:---|
| A. 状态转移概率 | 在"上一期 under"企业中 `P(离开/保持 under) ~ post`（LPM）；"上一期非 under"中 `P(进入 under) ~ post` | 政策是否改变进出 under 的概率 |
| B. 穿越事件 | `gen cross = (st_under != st_under_lag)`，`cross ~ post` 全样本 DID | 政策是否改变符号翻转频率 |
| C. 基期状态分组异质性 | `post × base_under`（base_under = 处理前最后一期 ε 符号，**时不变分组**）对 dev/under_intensity/over_intensity | 政策效应是否因初始状态而异——**不引入成员切换偏误** |
| D. ε 带符号 DID | `e_v1 ~ post` | 政策把 ε 整体推向哪个方向（区分"补足"=ε 上移 vs "双向压缩"=ε 不变、\|ε\| 降） |

实测（论文1，N≈22,341）：A/B/D 全部不显著（p>0.46）；C 全部高度显著——
dev：基期 over 企业 +0.009（n.s.）vs 基期 under 企业 **-2.009**（t=-11.89）；
under_intensity：+1.037 / -3.947***；over_intensity：-1.021*** / +1.931。

**解读范式**：政策效应集中于基期 under 企业（修复"本来就不足"的企业）+ 翻转频率未变
→ dev 下降主要是"向零点收敛"而非"错→错翻转"。基期 over 企业 under_intensity 上升
（与 over_intensity 下降几乎对消）→ 部分 over 企业转入不足，需进一步区分
"良性修正 vs 过度矫正"（见三边际分解的跨组边际）。

**关键洞见**：**按基期（处理前）状态分组是时不变分组，不引入成员切换偏误**——
这是"以此分组识别政策效应"的干净做法，与按当期状态分组有本质区别。

## 正式方案：无阈值连续分解（识别依据，零任意性）

设翻转 = 符号变化 `I(sign(ε_t) ≠ sign(ε_{t-1}))`（即 cross 变量）：

```
Δ|ε_t| = Δ|ε_t| × I(未翻转) + Δ|ε_t| × I(翻转)
          └── 收敛边际 ──┘     └── 跨组边际 ──┘
```

| 边际 | 变量 | 回答的问题 |
|:---|:---|:---|
| 收敛边际 | 未翻转企业 Δ\|ε\| ~ post | 错误**程度**是否减轻（组内改善） |
| 跨组边际 | 翻转企业 Δ\|ε\| ~ post | 穿过零点的企业翻转后偏离变小（-0.5→+0.1）还是变大（-0.5→+0.6）——**"错→错"被单独抓出** |
| 翻转频率 | `P(符号变化) ~ post` | 政策是否制造更多/更少跨组 |

**审稿应对**（无论结果如何都成为贡献点）：
- 翻转不显著 → 政策矫正精准，dev 下降全为真收敛，跨组担忧排除，主结果加固；
- 翻转显著为正 → 存在过度矫正，本身是发现（"识别精度提升但校准过头"），写进政策启示。

## θ 任意性原则（重要设计教训）

"命中区间"（|ε| ≤ θ 视为配置合理）直觉上吸引人，但 **25% 分位/中位数/均值均无理论依据**，
审稿人可攻击"为什么 25% 不是 30%"。任何固定阈值都是拍脑袋：

- **主分析必须绕开阈值**（用连续分解）；
- 阈值版本（θ=25% 分位、中位数双版本）**仅作描述性政策语言**（"多少企业回到合理区"），
  明确标注阈值敏感性，不做识别依据；
- 这样把软肋转为透明的稳健性展示。若一定要给 θ 非惯例依据：θ = 残差回归 RMSE
  （"偏离超过模型典型噪声水平"），但不同行业-年份 θ 不同，解释复杂，不如无阈值方案干净。

## 执行步骤

1. 构造翻转标识 × Δ|ε| 分解变量（`bysort Stkcd (year): gen d_abs = abs(e_v1) - abs(e_v1[_n-1])`，注意 year 连续性检查）
2. 三边际 DID：收敛边际 / 跨组边际 / 翻转频率（全样本 + PSM 样本）
3. 命中率描述统计（θ=25% 分位、中位数双版本，用处理前分布确定阈值）
4. 结果与四层检验合并为"动态配置效应"完整证据链
5. 文档同步（发现文件 F-xxx + 主回归结果 + 方法论沉淀）

## Stata 实现要点

- 上一期状态：`bysort Stkcd (year): gen st_lag = st[_n-1] if year - year[_n-1] == 1`
  （必须检查 year 连续性，非平衡面板里 `[_n-1]` 可能跨年）
- 基期状态分组：处理组取 `year < bureau_year` 的最后一年符号；从未处理组固定取某年（如 2017）；
  preserve 块中按企业去重后再 merge（`duplicates drop Stkcd, force`），否则 r(459)
- 交互项 `post × base_under` 中 base_under 被企业 FE 吸收是正常的（时不变），交互项仍可识别
- **组合系数（post + post×flip）用 `lincom post + 1.flip#c.post` 计算**——reghdfe 没有 `_varb` 矩阵
  （那是 ivreg2 的），`_varb[1.flip#c.post, post]` 报 r(111) "not found"；lincom 直接给 estimate/se，无需手算协方差
- **`tabstat` 的 if 条件必须放在逗号前**：`tabstat hit25 if ever_treated == 1, by(post) stats(mean)`；
  放逗号后（`tabstat hit25, by(post) stats(mean) if ...`）报 r(198) "option if not allowed"
- **preserve 块内 `summarize, detail` 的 r(p25)/r(p50) 等标量在 restore 后丢失**——
  阈值要在 restore 后重新计算（或先存 local 再 restore），否则生成 hit 变量时报"变量未定义"类错误

## 实测结果参考（论文1，2026-07-31）

- 命中率 DID：θ = 处理前 |ε| 的 p25=3.41 / p50=5.46；两个阈值下 `P(hit) ~ post` 均显著
  （全样本 +0.074~+0.086，t=4.6~5.1；PSM 样本 +0.072~+0.095），阈值敏感性良好
- 三边际分解：收敛边际不显著（全样本 +0.087 p=0.74；PSM -0.235 p=0.27），
  跨组边际 PSM 样本显著（-1.305, p=0.007）——翻转企业翻转方向以"向零点收敛"为主
- 解读范式：主效应主要由"把偏离企业推进命中区"（extensive margin）承载，
  组内微调（intensive margin）不是主要渠道——与基期分组结果（效应集中于基期 under 企业）自洽

## 交互项回归的系数解释（用户追问两次的概念，必须讲清）

模型 `Δ|ε| ~ post × flip` 中 **post 变量没有被做任何样本筛选/处理**——它是原 DID 交互项
（`Post_it = Treated_i × 1{t ≥ bureau_year_i}`，控制组恒为 0；企业 FE 吸收 Treated 主效应、
年份 FE 吸收时间主效应，故 post 系数即 DID 估计量）。**post 主效应系数自动等于参照组
（flip=0）的效应**，这是交互项回归的代数性质，不是样本操作：

- Flip=0 时：E[Δ|ε|] = β₁·Post → **β₁ = 收敛边际（未翻转企业效应）**
- Flip=1 时：E[Δ|ε|] = β₂ + (β₁+β₃)·Post → **β₁+β₃ = 跨组边际（翻转企业效应）**

交互项回归 ≡ 分组回归的紧凑写法（Flip=0 子样本跑 Y~post 得 β₁，Flip=1 子样本跑 Y~post
得 β₁+β₃，数值一致）。组合系数用 lincom 计算。**向用户解释时不要说"post 作为收敛边际"
（会被理解为修改了 post），要说"交互项设定让 post 的系数解释为 flip=0 组的效应"。**

## 基期定义（两个"基期"不可混淆）

1. **事件研究基期** = rel_time = -1（政策前一期，`ib4.rel_pos`）——所有事件研究系数的相对基准；
2. **基期状态分组基期**（base_under/base_over 的构造时点）= **处理前最后一期**：处理组取
   `bureau_year − 1` 的 ε 符号，从未处理组固定取某年（如 2017，伪基期对齐主体批次）。

分组基期**因成立批次而异**（多期 DID 必须交代）：2018 主体批次基期 = 2017（供给侧改革冲击后、
政策干预前）；2015 批次基期在样本外（用 2015 年符号近似）。报告"基期 under 企业"时要说明
"基期 = 处理前最后一期，约一半处理组企业为 2017 年"。

## PSM 样本主回归不显著但事件研究个别期显著 = 脉冲式效应（报告策略）

现象：under_intensity PSM 样本主回归 post = -0.269（p=0.333）不显著，但事件研究 t+1 -0.906**
（p=0.012）、t+3 -0.800**（p=0.032）显著。原因：**主回归 post 是政策后所有年份的平均效应**，
被不显著的期数（t=0、t+2、t+4~t+6）稀释；事件研究逐年拆开显示效应是**脉冲式**的
（只在特定年份显著）。

- 用户会质疑"不是显著的吗"——先核对 log 区分"主回归平均效应"与"事件研究逐期效应"再回答；
- 报告策略：脉冲式下降本身是"政策见效有滞后、有时点"的故事，**报告事件研究图/逐年系数
  而非只报平均效应**；同时如实标注 PSM 平均效应不显著，定位为"方向分解的组成部分"
  而非独立核心证据。
